# Boolean circuits, reproduced: maps and linear maps

Y. Lafont, *Towards an algebraic theory of Boolean circuits*, Journal of Pure and Applied Algebra 184 (2003), presents monoidal categories of maps by generators and relations: maps of finite sets, linear maps, Boolean functions and reversible circuits.
Each presentation is proved complete the same way: a rewrite system takes every diagram to a canonical form, and there is one canonical form for each map.
This notebook replays those proofs with the double-pushout rewriting of [`discopy.hypergraph`](https://docs.discopy.org/en/main/_api/discopy.hypergraph.html), after Bonchi et al., *String diagram rewrite theory* I and II.
A rule is a pair of hypergraphs, and a step plugs its right side into the pushout complement of a match of its left.
Each theorem is checked the way Lafont proves it: every diagram must reduce to the canonical form of the map it denotes.

This first part covers the maps of finite sets (§2) and the linear maps over a finite field (§3 and §3.3).

## Two departures from the paper

**The swap is wiring.**
Lafont's diagrams live in PROs, where the swap $\tau$ is a cell like any other and his rewrite systems count it.
Here a diagram is a hypergraph over `discopy.symmetric`, i.e. a string diagram up to the axioms of symmetric monoidal categories.
His relations that are such axioms hold on the nose: $\tau \circ \tau = 1$, the Yang–Baxter equation and the naturality of $\tau$.
So do his rules that only move a $\tau$.
Theorem 1, that $\tau$ and its two relations present the permutations $\mathfrak{S}$, becomes the coherence theorem for symmetric monoidal categories, built into the data structure.
So does Theorem 4 for the even permutations $\mathfrak{A}$ of §2.4, whose generator $\omega$ is a wiring too.
The monotone maps $\mathfrak{M}$ of §2.2 have no counterpart: they are the maps generated by $\mu$ and $\eta$ without $\tau$, and once $\tau$ is wiring, $\mu$ and $\eta$ generate all of $\mathfrak{F}$.

**Sums and copies are flattened.**
The commutativity $\mu \circ \tau = \mu$ cannot be oriented, and taking normal forms up to it is not enough.
Associativity, once oriented, leaves $\mu(a, \mu(b, c))$ and $\mu(b, \mu(a, c))$ apart, two terms that differ by associativity and commutativity together.
And $x + x = 0$ only fires when both copies of $x$ reach the same $\mu$.
So there is a sum $\mu_n : n \to 1$ and a copy $\delta_n : 1 \to n$ of every arity, with $\mu = \mu_2$, $\eta = \mu_0$, $\delta = \delta_2$ and $\varepsilon = \delta_0$.
Each rule is then a schema, instantiated for each match: flattening a sum fed by a sum is one rule for each pair of arities.
Normal forms are unique up to the order of the inputs of a sum and the outputs of a copy.
`equal` decides this, as an isomorphism of hypergraphs that forgets those orders.

## The encoding

A diagram has one type of wire, $x$.
Its semantics is a functor into `Matrix[int]`, read modulo the characteristic $p$ of the field $\mathbb{F}_p$.
The functor sends $\mu_n$ to `Matrix.merge(1, n)`, $\delta_n$ to `Matrix.copy(1, n)` and a scalar $a$ to $(a)$.
A `Matrix` composes rows by columns, so its array is the transpose of Lafont's matrix: one row for each input.

```python {.marimo}
from networkx.algorithms.isomorphism import is_isomorphic

from discopy.matrix import Matrix
from discopy.monoidal import Equation
from discopy.symmetric import Box, Diagram, Functor, Hypergraph, Ty

x = Ty("x")


def Sum(n: int) -> Box:
    """ The sum of n inputs, with mu = Sum(2) and eta = Sum(0). """
    return Box("μ", x ** n, x)


def Copy(n: int) -> Box:
    """ n copies of an input, with delta = Copy(2) and epsilon = Copy(0). """
    return Box("δ", x, x ** n)


def Scalar(a: int) -> Box:
    """ The multiplication by an element of the field. """
    return Box(str(a), x, x, data=a)


def kind(box: Box) -> str:
    return {"μ": "sum", "δ": "copy", "∧": "prod"}.get(box.name, "scalar")


mu, eta, delta, epsilon = Sum(2), Sum(0), Copy(2), Copy(0)

semantics = Functor(
    ob_map={x: 1}, cod=Matrix[int], ar_map=lambda box: (
        Matrix.merge(1, len(box.dom)) if kind(box) == "sum"
        else Matrix.copy(1, len(box.cod)) if kind(box) == "copy"
        else Matrix([[box.data]], 1, 1)).array)


def matrix(graph: Hypergraph, p: int) -> tuple[tuple[int, ...], ...]:
    """ The matrix of a hypergraph over the field with p elements. """
    array = semantics(graph.to_diagram()).array.reshape(
        len(graph.dom), len(graph.cod))
    return tuple(tuple(int(a) % p for a in row) for row in array)


def hypergraph(dom: list, boxes: list, cod: list) -> Hypergraph:
    """ A hypergraph from wires named by labels, a box as (box, ins, outs). """
    labels = list(dom) + list(cod) + [
        label for _, ins, outs in boxes for label in ins + outs]
    return Hypergraph(
        x ** len(dom), x ** len(cod), tuple(box for box, *_ in boxes),
        (tuple(dom), tuple((tuple(ins), tuple(outs))
                           for _, ins, outs in boxes), tuple(cod)),
        dict.fromkeys(labels, x))


COMMUTATIVE = {("dom", "sum"), ("dom", "prod"), ("cod", "copy")}


def forget_order(graph: Hypergraph):
    """ The labelled graph of a hypergraph, with sums and copies unordered. """
    result = graph.to_graph()
    for node, attributes in result.nodes(data=True):
        if node.kind in ("dom", "cod") and (
                node.kind, kind(graph.boxes[node.i])) in COMMUTATIVE:
            attributes["j"] = None
    return result


def equal(left: Hypergraph, right: Hypergraph) -> bool:
    """ Equality up to the order of the inputs of sums and outputs of copies. """
    return left.is_parallel(right) and is_isomorphic(
        forget_order(left), forget_order(right),
        node_match=lambda a, b: a == b)
```

## Rules for each match

A rule is found by a function of the host that returns its instance at one match: the left side, made of boxes of the host, the right side, and the match.
`step` is the double-pushout step of `discopy.hypergraph`.
Over a symmetric category the only pushout complement is the boundary complement (Bonchi et al. II, Definition 23), and the match must be convex, which `step` checks.
`normal_form` checks that every step keeps the meaning of the diagram, a check that the schemas are sound.

```python {.marimo}
def producers(graph: Hypergraph) -> dict:
    """ The box and port producing each spider, None for the domain. """
    result = dict.fromkeys(graph.dom_wires)
    for j, (_, outs) in enumerate(graph.box_wires):
        result.update((spider, j) for spider in outs)
    return result


def consumers(graph: Hypergraph) -> dict:
    """ The box consuming each spider, None for the codomain. """
    result = dict.fromkeys(graph.cod_wires)
    for j, (ins, _) in enumerate(graph.box_wires):
        result.update((spider, j) for spider in ins)
    return result


def instance(graph, boxes, dom, cod, right):
    """ The rule made of some boxes of the host, its boundary and a right side. """
    left = hypergraph(dom, [(graph.boxes[j], *graph.box_wires[j])
                            for j in boxes], cod)
    flat = list(dom) + [spider for j in boxes
                        for wires in graph.box_wires[j] for spider in wires]
    return left, right, (tuple(dict.fromkeys(flat + list(cod))), tuple(boxes))


def step(graph, left, right, match):
    assert graph.is_convex(match)
    context, = graph.complements(left, match)
    return context.plug(right)


def names(n: int, prefix: str) -> list[str]:
    return [f"{prefix}{i}" for i in range(n)]
```

Four schemas, each derived from Lafont's relations:

* `flatten`: associativity and unit of the sums and copies, their commutativity being absorbed. A sum with a sum on one of its inputs is one sum, dually for copies, and a sum or a copy of arity one is the identity.
* `scale`: the scalars of Fig. 36. The scalar $1$ is the identity, $0$ is $\eta \circ \varepsilon$, and two scalars in a row are their product.
* `push`: the bialgebra relations of Fig. 13 and the scalars of Fig. 36, which move a copy above a sum or a scalar, and a scalar above a sum.
* `parallel`: $a + b = \mu \circ (a \mid b) \circ \delta$ of Fig. 36, which is $x + x = 0$ over $\mathbb{Z}_2$. All the edges from one copy to one sum become one, scaled by their sum. Taking them all at once is what keeps the match convex once the other rules are done, and a match that is not convex, the copy reaching the sum through some other box too, waits for them.

```python {.marimo}
def flatten(graph, p):
    found = producers(graph), consumers(graph)
    for j, box in enumerate(graph.boxes):
        (ins, outs), side = graph.box_wires[j], kind(box) == "copy"
        if kind(box) == "scalar":
            continue
        if len((ins, outs)[side]) == 1:
            return instance(graph, [j], ins, outs, Hypergraph.id(x))
        for k, spider in enumerate((ins, outs)[side]):
            i = found[side][spider]
            if i is None or graph.boxes[i].name != box.name:
                continue
            inner = graph.box_wires[i][side]
            rest = (ins, outs)[side][:k] + (ins, outs)[side][k + 1:]
            n = len(inner + rest)
            if side:
                return instance(graph, [j, i], ins, list(inner + rest),
                                Box(box.name, x, x ** n).to_hypergraph())
            return instance(graph, [i, j], list(inner + rest), outs,
                            Box(box.name, x ** n, x).to_hypergraph())
    return None


def scale(graph, p):
    found = producers(graph)
    for j, box in enumerate(graph.boxes):
        if kind(box) != "scalar":
            continue
        ins, outs = graph.box_wires[j]
        if box.data % p == 1:
            return instance(graph, [j], ins, outs, Hypergraph.id(x))
        if box.data % p == 0:
            return instance(graph, [j], ins, outs, hypergraph(
                ["i"], [(epsilon, ["i"], []), (eta, [], ["o"])], ["o"]))
        i = found[ins[0]]
        if i is not None and kind(graph.boxes[i]) == "scalar":
            product = Scalar(box.data * graph.boxes[i].data % p)
            return instance(graph, [i, j], graph.box_wires[i][0], outs,
                            product.to_hypergraph())
    return None


def push(graph, p):
    found = consumers(graph)
    for j, box in enumerate(graph.boxes):
        ins, outs = graph.box_wires[j]
        i = found[outs[0]] if kind(box) != "copy" else None
        if i is None:
            continue
        below, cod = graph.boxes[i], graph.box_wires[i][1]
        n, m = len(ins), len(cod)
        if kind(box) in ("sum", "prod") and kind(below) == "copy":
            right = hypergraph(names(n, "i"), [
                (Copy(m), [f"i{a}"], [f"e{a},{b}" for b in range(m)])
                for a in range(n)] + [
                (box, [f"e{a},{b}" for a in range(n)], [f"o{b}"])
                for b in range(m)], names(m, "o"))
        elif (kind(box), kind(below)) == ("scalar", "copy"):
            right = hypergraph(["i"], [(Copy(m), ["i"], names(m, "e"))] + [
                (box, [f"e{b}"], [f"o{b}"]) for b in range(m)], names(m, "o"))
        elif (kind(box), kind(below)) == ("sum", "scalar"):
            right = hypergraph(names(n, "i"), [
                (below, [f"i{a}"], [f"e{a}"]) for a in range(n)] + [
                (Sum(n), names(n, "e"), ["o"])], ["o"])
        else:
            continue
        return instance(graph, [j, i], ins, cod, right)
    return None


def parallel(graph, p):
    found = producers(graph)
    for j, box in enumerate(graph.boxes):
        if kind(box) != "sum":
            continue
        ins, outs = graph.box_wires[j]
        edges = {}
        for k, spider in enumerate(ins):
            source, scalar = found[spider], None
            if source is not None and kind(graph.boxes[source]) == "scalar":
                scalar = source
                source = found[graph.box_wires[scalar][0][0]]
            if source is not None and kind(graph.boxes[source]) == "copy":
                edges.setdefault(source, []).append((k, scalar))
        for i, these in edges.items():
            if len(these) < 2:
                continue
            total = sum(1 if s is None else graph.boxes[s].data
                        for _, s in these) % p
            used = [ins[k] if s is None else graph.box_wires[s][0][0]
                    for k, s in these]
            others = [s for s in graph.box_wires[i][1] if s not in used]
            ports = {k for k, _ in these}
            rest = [s for k, s in enumerate(ins) if k not in ports]
            a, b = len(others), len(rest)
            if total == 0:
                edge = [(Copy(a), ["c"], names(a, "o")),
                        (Sum(b), names(b, "r"), ["t"])]
            elif total == 1:
                edge = [(Copy(a + 1), ["c"], names(a, "o") + ["e"]),
                        (Sum(b + 1), ["e"] + names(b, "r"), ["t"])]
            else:
                edge = [(Copy(a + 1), ["c"], names(a, "o") + ["e"]),
                        (Scalar(total), ["e"], ["f"]),
                        (Sum(b + 1), ["f"] + names(b, "r"), ["t"])]
            scalars = [s for _, s in these if s is not None]
            result = instance(
                graph, [i] + scalars + [j],
                list(graph.box_wires[i][0]) + rest, others + list(outs),
                hypergraph(["c"] + names(b, "r"), edge, names(a, "o") + ["t"]))
            if graph.is_convex(result[2]):
                return result
    return None


def normal_form(graph, rules, p, meaning=matrix, limit=10_000):
    """ Rewrite with the first rule that applies, checking each step. """
    before = meaning(graph, p)
    for steps in range(limit):
        found = next((found for rule in rules
                      if (found := rule(graph, p)) is not None), None)
        if found is None:
            return graph, steps
        graph = step(graph, *found)
        assert meaning(graph, p) == before
    raise RuntimeError(f"no normal form in {limit} steps")
```

## Canonical forms

A canonical form is, in Lafont's words, a straightforward transcription of the matrix.
Each input is copied once for each non-zero entry of its row.
Each copy goes through the scalar of its entry, unless that scalar is 1, into the sum of its column.
A copy or a sum of arity one is a wire.

```python {.marimo}
def canonical(rows, p, inputs, outputs):
    """ The canonical form of a matrix, with one row for each input. """
    boxes, ends = [], {b: [] for b in range(outputs)}
    for a in range(inputs):
        targets = [b for b in range(outputs) if rows[a][b] % p]
        wires = [f"e{a},{b}" for b in targets] if len(targets) != 1 else []
        if len(targets) != 1:
            boxes.append((Copy(len(targets)), [f"i{a}"], wires))
        for b, wire in zip(targets, wires or [f"i{a}"]):
            if rows[a][b] % p != 1:
                boxes.append((Scalar(rows[a][b] % p), [wire], [f"s{a},{b}"]))
                wire = f"s{a},{b}"
            ends[b].append(wire)
    cod = [ends[b][0] if len(ends[b]) == 1 else f"o{b}"
           for b in range(outputs)]
    boxes += [(Sum(len(ends[b])), ends[b], [f"o{b}"])
              for b in range(outputs) if len(ends[b]) != 1]
    return hypergraph(names(inputs, "i"), boxes, cod)


def random_diagram(rng, generators, inputs, size) -> Hypergraph:
    """ Random boxes, each on random wires, and the wires shuffled at the end. """
    wires, boxes, fresh = list(range(inputs)), [], inputs
    for _ in range(size):
        box = rng.choice(generators)
        if len(box.dom) > len(wires):
            continue
        ins = [wires.pop(rng.randrange(len(wires))) for _ in box.dom]
        outs = list(range(fresh, fresh + len(box.cod)))
        boxes.append((box, ins, outs))
        wires, fresh = wires + outs, fresh + len(outs)
    rng.shuffle(wires)
    return hypergraph(list(range(inputs)), boxes, wires)


def check(generators, rules, p, trials, seed=0,
          meaning=matrix, canonical=canonical):
    """ Random diagrams each reduce to the canonical form of their meaning. """
    import random
    rng, steps = random.Random(seed), []
    for _ in range(trials):
        graph = random_diagram(rng, generators, rng.randint(0, 3), 12)
        result, count = normal_form(graph, rules, p, meaning)
        assert equal(result, canonical(
            meaning(graph, p), p, len(graph.dom), len(graph.cod)))
        steps.append(count)
    return max(steps), sum(steps) / len(steps)
```

## Maps of finite sets: Theorem 3

The category $\mathfrak{F}$ of maps between the sets $\{1, \dots, n\}$, with disjoint union as tensor, is generated by $\mu$, $\eta$ and $\tau$.
Of the seven relations of Fig. 5, the four on $\tau$ alone or on its naturality are absorbed.
What remains is associativity, the unit and commutativity, i.e. $\mathfrak{F}$ is the free symmetric monoidal category on a commutative monoid.
The matrix of a map has one 1 in each row, and `flatten` alone takes every diagram to its canonical form: one sum for each element of the codomain, of its preimage.
The surjections $\mathfrak{F}_{surj}$ are generated by $\mu$ and the same rules.
The injections $\mathfrak{F}_{inj}$ are generated by $\eta$, with no relation left, since Lafont's three are on $\tau$.

```python {.marimo}
relations_F = {
    "associativity": (mu @ x >> mu, x @ mu >> mu),
    "unit": (eta @ x >> mu, Diagram.id(x)),
    "commutativity": (Diagram.swap(x, x) >> mu, mu)}
for _left, _right in relations_F.values():
    _left, _right = _left.to_hypergraph(), _right.to_hypergraph()
    assert matrix(_left, 2) == matrix(_right, 2)
    assert equal(normal_form(_left, [flatten], 2)[0],
                 normal_form(_right, [flatten], 2)[0])
results_F = {name: check(generators, [flatten], 2, 40) for name, generators in [
    ("𝔉", [mu, eta]), ("𝔉_surj", [mu]), ("𝔉_inj", [eta])]}
mo.md("\n".join(["| category | most steps | mean steps |", "|---|---|---|"] + [
    f"| ${name}$ | {most} | {mean:.1f} |"
    for name, (most, mean) in results_F.items()]))
```

## Linear maps over $\mathbb{Z}_2$: Theorem 5

$\mathbf{L}(\mathbb{Z}_2)$ has the linear maps $\mathbb{Z}_2^p \to \mathbb{Z}_2^q$, with direct sum as tensor, generated by $\tau$, $\delta$, $\varepsilon$, $\mu$ and $\eta$.
The relations of Fig. 13 that are not symmetric monoidal axioms are those of a commutative monoid, of a cocommutative comonoid, the four of a bialgebra, and $\mu \circ \delta = \eta \circ \varepsilon$, i.e. $x + x = 0$.
Each holds in the semantics, and its two sides have the same normal form:

```python {.marimo}
relations_L = dict(relations_F, **{
    "coassociativity": (delta >> delta @ x, delta >> x @ delta),
    "counit": (delta >> epsilon @ x, Diagram.id(x)),
    "cocommutativity": (delta >> Diagram.swap(x, x), delta),
    "bialgebra": (mu >> delta, delta @ delta
                  >> x @ Diagram.swap(x, x) @ x >> mu @ mu),
    "copied unit": (eta >> delta, eta @ eta),
    "discarded sum": (mu >> epsilon, epsilon @ epsilon),
    "discarded unit": (eta >> epsilon, Diagram.id(Ty())),
    "x + x = 0": (delta >> mu, epsilon >> eta)})
rules_L = [flatten, scale, push, parallel]
for _left, _right in relations_L.values():
    _left, _right = _left.to_hypergraph(), _right.to_hypergraph()
    assert matrix(_left, 2) == matrix(_right, 2)
    assert equal(normal_form(_left, rules_L, 2)[0],
                 normal_form(_right, rules_L, 2)[0])
Equation(*relations_L["bialgebra"])
```

Every diagram reduces to the canonical form of its matrix, which is Theorem 5 on these diagrams: two diagrams with the same matrix have the same normal form, up to the order of sums and copies, by schemas each derived from the relations.
The random diagrams have up to twelve generators on up to three inputs:

```python {.marimo}
results_L = check([mu, eta, delta, epsilon], rules_L, 2, 60)
mo.md(f"Sixty random diagrams over $\\mathbb{{Z}}_2$: at most {results_L[0]} "
      f"steps, {results_L[1]:.1f} on average.")
```

For instance, a diagram with three copies of one input summed into one output reduces to a single wire:

```python {.marimo}
_three = delta >> x @ delta >> mu @ x >> mu
_result, _ = normal_form(_three.to_hypergraph(), rules_L, 2)
assert equal(_result, Hypergraph.id(x))
```

## Linear maps over a finite field: §3.3

Over any field $K$, Lafont adds a generator $a : 1 \to 1$ for each $a \in K$, the multiplication by $a$.
He replaces $x + x = 0$ by the eight relations of Fig. 36 that are not on $\tau$.
A scalar goes through copies and sums, discards and units.
Scalars multiply, $1$ is the identity and $0$ is $\eta \circ \varepsilon$.
And $a + b = \mu \circ (a \mid b) \circ \delta$.
Here $K = \mathbb{F}_p$, and these relations hold for all $a$ and $b$, the case $p = 2$ giving back the previous section:

```python {.marimo}
def relations_K(a, b, p):
    """ The relations of Fig. 36 that are not on the swap. """
    return {
        "copied scalar": (Scalar(a) >> delta, delta >> Scalar(a) @ Scalar(a)),
        "discarded scalar": (Scalar(a) >> epsilon, epsilon),
        "scaled sum": (mu >> Scalar(a), Scalar(a) @ Scalar(a) >> mu),
        "scaled unit": (eta >> Scalar(a), eta),
        "product": (Scalar(b) >> Scalar(a), Scalar(a * b % p)),
        "one": (Scalar(1), Diagram.id(x)),
        "sum": (Scalar((a + b) % p), delta >> Scalar(a) @ Scalar(b) >> mu),
        "zero": (Scalar(0), epsilon >> eta)}


for _p in (2, 3, 5):
    for _a in range(_p):
        for _b in range(_p):
            for _left, _right in relations_K(_a, _b, _p).values():
                _left, _right = _left.to_hypergraph(), _right.to_hypergraph()
                assert matrix(_left, _p) == matrix(_right, _p)
                assert equal(normal_form(_left, rules_L, _p)[0],
                             normal_form(_right, rules_L, _p)[0])
results_K = {_p: check([mu, eta, delta, epsilon] + [
    Scalar(_a) for _a in range(_p)], rules_L, _p, 40) for _p in (3, 5)}
mo.md("\n".join(["| field | most steps | mean steps |", "|---|---|---|"] + [
    f"| $\\mathbb{{F}}_{_p}$ | {most} | {mean:.1f} |"
    for _p, (most, mean) in results_K.items()]))
```

## Boolean functions: Theorem 10

$\mathfrak{F}[2]$ has the functions $\mathbb{Z}_2^p \to \mathbb{Z}_2^q$, with the cartesian product as tensor.
It adds two generators to those of $\mathbf{L}(\mathbb{Z}_2)$: the conjunction $\mu' : 2 \to 1$ and the truth $\eta' : 0 \to 1$, flattened as $\wedge_n : n \to 1$ with $\mu' = \wedge_2$ and $\eta' = \wedge_0$.
The semantics is now a functor into `python.Function`, which sends $x$ to `int` and each generator to its function on bits, with the cartesian product as tensor: Lafont's classical case.

```python {.marimo}
from itertools import product

from discopy import python
from discopy.utils import tuplify, untuplify


def Prod(n: int) -> Box:
    """ The conjunction of n inputs, with mu' = Prod(2) and eta' = Prod(0). """
    return Box("∧", x ** n, x)


conjunction, truth = Prod(2), Prod(0)


def function(box: Box):
    """ The function of a sum, a copy or a conjunction, on bits. """
    if kind(box) == "copy":
        return lambda bit: untuplify((bit, ) * len(box.cod))
    if kind(box) == "sum":
        return lambda *bits: sum(bits) % 2
    return lambda *bits: int(all(bits))


boolean = Functor(ob_map={x: int}, ar_map=function, cod=python.Function)


def truth_table(graph: Hypergraph, p: int = 2) -> dict:
    """ The outputs of a Boolean circuit on each input. """
    circuit = boolean(graph.to_diagram())
    return {bits: tuplify(circuit(*bits))
            for bits in product((0, 1), repeat=len(graph.dom))}
```

The canonical form of a Boolean function is its algebraic normal form.
Each output is a sum of monomials, each monomial a conjunction of inputs, which are copied as many times as the monomials need them.
The coefficient of a monomial is the sum of the function over the inputs below it, its Möbius transform.

```python {.marimo}
def normal_polynomial(table, p, inputs, outputs):
    """ The algebraic normal form of each output, as a diagram. """
    monomials = [[s for s in product((0, 1), repeat=inputs) if sum(
        table[bits][b] for bits in product((0, 1), repeat=inputs)
        if all(i <= j for i, j in zip(bits, s))) % 2] for b in range(outputs)]
    boxes, wire = [], {}
    for a in range(inputs):
        places = [(b, m) for b in range(outputs)
                  for m, s in enumerate(monomials[b]) if s[a]]
        wires = [f"c{a},{b},{m}" for b, m in places]\
            if len(places) != 1 else [f"i{a}"]
        if len(places) != 1:
            boxes.append((Copy(len(places)), [f"i{a}"], wires))
        wire.update(((b, m, a), w) for (b, m), w in zip(places, wires))
    cod = []
    for b in range(outputs):
        terms = []
        for m, s in enumerate(monomials[b]):
            ins = [wire[b, m, a] for a in range(inputs) if s[a]]
            if len(ins) != 1:
                boxes.append((Prod(len(ins)), ins, [f"m{b},{m}"]))
            terms.append(ins[0] if len(ins) == 1 else f"m{b},{m}")
        if len(terms) != 1:
            boxes.append((Sum(len(terms)), terms, [f"o{b}"]))
        cod.append(terms[0] if len(terms) == 1 else f"o{b}")
    return hypergraph(names(inputs, "i"), boxes, cod)
```

Lafont's ten relations of Fig. 40 that are not on $\tau$ say that a conjunction and the truth can be copied and discarded, that they form a commutative monoid, that the conjunction distributes over sums, that $0 \wedge x = 0$ and that $x \wedge x = x$.
Two schemas of part one cover the first five, once `flatten` and `push` take conjunctions as they take sums.
Three more cover the rest:

* `distribute`: $(x + y) \wedge z = (x \wedge z) + (y \wedge z)$ for a conjunction fed by a sum, $0 \wedge z = 0$ when the sum is empty.
* `idempotence`: $x \wedge x = x$ and $x + x = 0$, for a conjunction or a sum fed twice by one copy. Part one's `parallel` did the latter, but here another path from the copy to the sum may go through a conjunction, so it too takes the convex hull.
* `cancel`: two equal monomials summed cancel, i.e. $m + m = 0$, from $x + x = 0$ once both are seen as copies of one conjunction.

The third has to be careful.
Two equal monomials read the same copies, but a third monomial of the same sum may read one of those copies too.
That gives a path from a copy to the sum outside the two monomials, so the match is not convex.
`rule` takes the convex hull of the boxes a schema is about, i.e. those boxes and every box on a path between two of them.
Its right side is a transformation of those boxes, keeping the boundary.

```python {.marimo}
def rule(graph, core, transform):
    """ The rule on the convex hull of some boxes, its right side transformed. """
    made, used = producers(graph), consumers(graph)

    def reach(start, step):
        seen, todo = set(), list(start)
        while todo:
            for k in step(todo.pop()):
                if k is not None and k not in seen:
                    seen.add(k)
                    todo.append(k)
        return seen

    below = reach(core, lambda j: [used[s] for s in graph.box_wires[j][1]])
    above = reach(core, lambda j: [made[s] for s in graph.box_wires[j][0]])
    boxes = {j: (graph.boxes[j], *map(list, graph.box_wires[j]))
             for j in sorted(set(core) | below & above)}
    dom = [s for _, ins, _ in boxes.values() for s in ins
           if made[s] not in boxes]
    cod = [s for _, _, outs in boxes.values() for s in outs
           if used[s] not in boxes]
    inside = [s for _, ins, outs in boxes.values() for s in ins + outs]
    return (hypergraph(dom, list(boxes.values()), cod),
            hypergraph(dom, transform(dict(boxes)), cod),
            (tuple(dict.fromkeys(dom + inside + cod)), tuple(boxes)))


def unwire(boxes, drop):
    """ The boxes without the wires to drop, shrunk to the wires left. """
    result = []
    for box, ins, outs in boxes.values():
        ins = [s for s in ins if s not in drop]
        outs = [s for s in outs if s not in drop]
        if (len(ins), len(outs)) != (len(box.dom), len(box.cod)):
            box = Box(box.name, x ** len(ins), x ** len(outs))
        result.append((box, ins, outs))
    return result


def distribute(graph, p):
    made = producers(graph)
    for j, box in enumerate(graph.boxes):
        ins = graph.box_wires[j][0] if kind(box) == "prod" else ()
        for k, i in enumerate(made[s] for s in ins):
            if i is None or kind(graph.boxes[i]) != "sum":
                continue

            def spread(boxes, i=i, j=j, k=k):
                (_, terms, _), (_, ins, outs) = boxes.pop(i), boxes.pop(j)
                rest, n = ins[:k] + ins[k + 1:], len(terms)
                return [(Copy(n), [z], [f"c{a},{b}" for b in range(n)])
                        for a, z in enumerate(rest)] + [
                    (Prod(len(ins)), [y] + [f"c{a},{b}" for a in range(
                        len(rest))], [f"t{b}"]) for b, y in enumerate(terms)
                ] + [(Sum(n), names(n, "t"), outs)] + list(boxes.values())
            return rule(graph, [i, j], spread)
    return None


def idempotence(graph, p):
    made = producers(graph)
    for j, box in enumerate(graph.boxes):
        if kind(box) not in ("prod", "sum"):
            continue
        copies = {}
        for s in graph.box_wires[j][0]:
            if made[s] is not None and kind(graph.boxes[made[s]]) == "copy":
                copies.setdefault(made[s], []).append(s)
        for i, wires in copies.items():
            keep = 1 if kind(box) == "prod" else len(wires) % 2
            if len(wires) > 1:
                return rule(graph, [i, j], lambda boxes, drop=set(
                    wires[keep:]): unwire(boxes, drop))
    return None


def cancel(graph, p):
    made = producers(graph)
    for j, box in enumerate(graph.boxes):
        seen = {}
        for i in (made[s] for s in graph.box_wires[j][0]
                  if kind(box) == "sum"):
            sources = [made[s] for s in graph.box_wires[i][0]]\
                if i is not None and kind(graph.boxes[i]) == "prod" else [None]
            if any(s is None or kind(graph.boxes[s]) != "copy"
                   for s in sources):
                continue
            key = tuple(sorted(sources))
            if key not in seen:
                seen[key] = i
                continue
            pair = (seen[key], i)
            drop = {s for n in pair for wires in graph.box_wires[n]
                    for s in wires}
            return rule(graph, list(key) + list(pair) + [j],
                        lambda boxes, pair=pair, drop=drop: unwire({
                            n: b for n, b in boxes.items() if n not in pair},
                            drop))
    return None


rules_F2 = [flatten, push, distribute, idempotence, cancel]
```
